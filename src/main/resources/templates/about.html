About DevOpsPulse

DevOpsPulse is a single, unified Spring Boot application built to demonstrate a complete, production-style DevOps lifecycle end to end: from local development through source control, automated builds, testing, containerization, distributed CI automation, and cloud deployment with continuous health monitoring.

Rather than treating infrastructure as an afterthought, DevOpsPulse is intentionally weighted toward the operational tooling that keeps a real service running in production — roughly 80% infrastructure and DevOps engineering, 20% user-facing UI.

Project Objectives

Provide a working reference implementation of a Java Spring Boot service that can be built with Gradle, verified with JUnit 5, packaged into a minimal Alpine-based Docker image, orchestrated through a Jenkins Controller-Agent pipeline, and promoted through Azure Pipelines into Azure Container Registry and Azure App Service, with health verification enforced at every stage.

Architecture

The application follows a conventional layered Spring MVC architecture: web and REST controllers delegate to a service layer that computes runtime and build metadata, which is rendered either as JSON (for automation and health checks) or as server-side Thymeleaf HTML (for the human-facing dashboard). The same artifact serves both purposes so that what operators see on the dashboard is always backed by the same data automated pipelines rely on for verification.
